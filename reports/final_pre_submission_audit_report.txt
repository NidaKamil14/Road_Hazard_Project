## 10. OSRM Routing
- Status: PASS
- Routing Engine: OSRM Public Routing API (https://router.project-osrm.org) with polyline decoding.
- Routing Pipeline:
  - Retrieves alternative drivable route geometries between user origin and destination.
  - Queries nearby PostGIS hazards along candidate paths using ST_DWithin with geography cast.
  - Applies calibrated hazard penalty equation factoring proximity, severity weight, and priority score.
  - Selects lowest composite cost route: Cost = Base Duration + Safety Penalty.
  - Converts polyline coordinates into Leaflet [lat, lng] format without latitude/longitude inversion.
