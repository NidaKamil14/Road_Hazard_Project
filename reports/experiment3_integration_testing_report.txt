10. ERRORS ENCOUNTERED & REMEDIATION
================================================================================
1. Pytest SQLite dependency override leakage:
   - Cause:  test_auth.py globally set app.dependency_overrides[get_db] to an in-memory
             SQLite instance without PostGIS support.
   - Remedy: Added clean_dependency_overrides autouse fixture in test_experiment3_integration.py
             to restore the real PostgreSQL/PostGIS connection for integration testing.

2. Standalone Startup Session Key:
   - Cause:  backend/main.py requires SESSION_SECRET_KEY of at least 32 characters.
   - Remedy: Configured 64-character SESSION_SECRET_KEY in backend/.env.

3. Frontend / Backend Port Alignment:
   - Cause:  Backend main.py defaulted to 8000, while frontend app.js, map.js, auth.js
             configured port 5000.
   - Remedy: Updated main.py to default to port 5000 (configurable via PORT env var)
             and added port 5000 to CORS ALLOWED_ORIGINS.
