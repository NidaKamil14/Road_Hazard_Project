## 10. Issues Fixed
1. Geolocation Browser Timeout / Denial Fallback (frontend/app.js):
   - Issue: If a browser or headless agent blocked or timed out on GPS permissions, performDetection threw an unhandled error and completely prevented image detection.
   - Fix: Added a graceful fallback to default coordinates (Pune City: lat 18.5204, lng 73.8567), allowing detection and persistence to succeed smoothly under any browser permission state.

2. Detection Card Metadata Display (frontend/app.js):
   - Issue: Detection cards only showed class name and confidence, omitting bounding boxes and backend-calculated severity and priority.
   - Fix: Updated saveHazardsToDatabase and populateResultsData to capture server-returned severity, priority score, priority level, and bounding box coordinates [x1, y1, x2, y2] on each detection item card.

3. CORS Allowed Origins Alignment (backend/main.py):
   - Issue: Frontend served on port 8080 was not in backend CORS whitelist.
   - Fix: Added http://localhost:8080 and http://127.0.0.1:8080 to ALLOWED_ORIGINS.

4. Database Admins Table Initialization (backend/init_db.py):
   - Issue: PostgreSQL database lacked the 'admins' table schema for authority logins.
   - Fix: Ran init_db.py to create the admins table non-destructively and seeded an active administrator account with Argon2 password hashing.

5. Pytest Sys.Path Discovery (backend/tests/conftest.py):
   - Issue: Running pytest without explicit PYTHONPATH caused ModuleNotFoundError for backend imports.
   - Fix: Added backend/tests/conftest.py to ensure project root is always at the head of sys.path.
