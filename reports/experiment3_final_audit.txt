SECTION 5: METHODOLOGY & SCIENTIFIC COMPARABILITY AUDIT
================================================================================
CRITICAL SCIENTIFIC ASSESSMENT: ARE EXPERIMENT 2 AND EXPERIMENT 3 DIRECTLY COMPARABLE?

5.1 Strictly Identical Factors:
  [x] Model Architecture:   YOLO11s (9.46M parameters, 21.7 GFLOPs) in both experiments.
  [x] Input Resolution:     800 x 800 in both experiments.
  [x] Hardware:             NVIDIA RTX PRO 2000 Blackwell (16 GB VRAM) in both experiments.
  [x] Evaluation Tool:      Ultralytics model.val() standard COCO evaluator (IoU 0.50:0.95).
  [x] Evaluation Settings:  batch=16, imgsz=800, device=0, conf=0.001, iou=0.6.
  [x] Class Ontology:       Exact same 4 target IDs (0: pothole, 1: crack, 2: waterlog, 3: barrier).

5.2 Genuine Apples-to-Apples Comparisons (Identical Test Subsets):
  - Class 0 (Pothole) and Class 1 (Road Crack):
    Both experiments evaluated on the EXACT SAME 5,758 RDD2022 test images (531 pothole and
    3,322 road crack images). Therefore, the gains of +6.45% in pothole mAP50 and +14.35% in
    road crack mAP50 are pure, direct, apples-to-apples performance increases on identical test scenes.

5.3 Methodological Differences & Limitations (Must be explicitly reported):
  1. Non-Identical Test Sets for Waterlogging and Construction Barrier:
     * Exp 2 Waterlogging Test Set: Only 94 images from a small subset.
     * Exp 3 Waterlogging Test Set: 1,118 images (11.9x larger, covering diverse real-world flood scenes).
     * Exp 2 Barrier Test Set:      1,803 images from Roboflow with 45.4% sequence leakage.
     * Exp 3 Barrier Test Set:      894 images from ROADWork partitioned strictly by video sequence (0% leakage).
     * Impact: The waterlogging and barrier test comparisons reflect performance on their respective,
       updated test splits. Exp 3 was evaluated on much larger and genuinely unseen sequences.
  2. Sequence Leakage Correction:
     * Exp 2 had severe sequence leakage in the construction class (Roboflow default random split).
     * Exp 3 completely eliminated sequence leakage (0.0% overlap between train, val, and test).
     * Despite testing on completely unseen sequences, barrier mAP50 surged from 37.18% to 77.64%,
       proving that the improvement is genuine generalization.
  3. Training Epoch Budget:
     * Exp 2 was trained for 50 epochs (8,366 virtual samples per epoch = 418,300 total image exposures).
     * Exp 3 was trained for 100 epochs (37,778 samples per epoch = 3,777,800 total image exposures).
     * Exp 3 had ~9x more cumulative gradient update exposures than Exp 2.
